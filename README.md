# Backend-Biblioteca  
Integrantes:
Leon Gamez Fernando / Camacho Guerra Jacobo / Garcia Rosales Karen Nicol   
Descripcion General De Nuestro Proyecto:
Este proyecto es un sistema automático que facilita la administración de una biblioteca (préstamos, devoluciones y control de libros). Funciona de manera que hace el trabajo repetitivo por ti:
​Todo se actualiza solo: Cuando alguien pide o devuelve un libro, el sistema ajusta el inventario al instante y envía los avisos necesarios sin que tengas que hacerlo a mano.
​Cero enredos: Mantiene la información siempre correcta trabajando de forma invisible en segundo plano, evitando errores o datos perdidos.
